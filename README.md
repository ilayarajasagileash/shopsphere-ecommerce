# ShopSphere

ShopSphere is a responsive e-commerce product catalog built using HTML, CSS, and JavaScript.

## Features

- Responsive design
- Client-side routing
- Product search
- Category filtering
- Price sorting
- Product details
- Shopping cart
- Quantity management
- Dark mode
- LocalStorage
- Lazy-loaded product images

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
